程式碼課程前 — 技術環境設定

從 Module 2 開始，你會開始看到實作型程式碼示範課程。在開始開發 AI 應用之前，我們需要先準備一個適合整門課程使用的現代 Python 開發環境。

好消息是，這個設定只需做一次。環境一旦正確配置完成，之後課程中的每個模組都會沿用相同的工作流程。

這門課程設計成讓你可以立即運行並學習完整、可工作的實作。每一個教學影片中展示的課程，實際上都已經存在於儲存庫中的 project-completed/ 目錄。這是推薦的學習路徑，因為它能讓你先聚焦於理解 AI 概念與軟體工程技術，而不需要一開始就從零開始建構每一個課程。

如果你想要更進一步做動手練習，你也可以找到對應的 project-todo/ 目錄。這些檔案包含 scaffolded 的實作範本與 TODO 區段，讓你在理解完完整版本後自行完成它們。這是一個選擇性挑戰，目的是延伸學習。

建議學習流程

  • 先看課程內容。

  • 從 project-completed/ 執行完成版範例。

  • 研究程式碼如何運作。

  • 修改與實驗範例。

  • 如果需要，再用 project-todo/ 內的檔案自己重建該課程。

在後續課程中，你主要會使用以下工具：

  • Python 3.11+

  • Visual Studio Code

  • Git

  • Virtual Environments

  • Large Language Model APIs

  • Streamlit

  • 課程儲存庫

在本節結束時，你將擁有一個完整的環境，能夠執行整門課程中所示的所有專案。

語言 / 框架選擇

這門課程使用 Python，這是一門非常流行且推薦的語言。這裡學到的方法也可以很容易地套用到其他程式語言與框架，甚至可透過 AI 工具輕鬆移植。
