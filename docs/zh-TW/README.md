# 給軟體工程師的 AI

課程作者：Ifeoluwa Mobolaji Olawoye

這門課程幫助軟體工程師從 AI 工具使用者，成長為 AI 時代的系統設計者。它不把 AI 當成黑盒，而是聚焦於現代 AI 產品背後的核心模式：聊天介面、檢索系統、代理（agents）與可上線的 AI 架構。

## 課程目的

現代工程工作愈來愈多地位於軟體交付、產品思維與 AI 系統設計的交會點。這門課程適合想要更有信心地搭建 AI 專案、理解模型行為，並交付可靠、紮實且實用的真實系統的工程師。

## 課程大綱

### 模組 1：基礎與思維
- 1.1 — 為什麼這個轉變重要：解釋 AI 平台轉型，以及現代 AI 系統的三大核心模式。
- 1.2 — 為什麼這對你很重要：將 AI 變化連結到職涯發展與個人價值。
- 1.3 — 你的技能是安全的：釐清常見恐懼，並重新定位既有經驗的優勢。
- 1.4 — 完整學習路徑：呈現整門課的學習藍圖與進度安排。

### 模組 2：AI 基礎
- 2.0 — [技術環境設定](./setup.html)：準備本機環境、編輯器與 API 存取。
- 2.1 — LLM 的運作原理：解釋大型語言模型的高層概念。
- 2.2 — Tokens、Context 與 Completion：涵蓋成本、上下文限制與 prompt 行為。
- 2.3 — Transformer 架構：介紹塑造現代 AI 的關鍵模型概念。
- 2.4 — Prompting、Retrieval 與 Fine-Tuning：將 prompt 設計模式與改進策略連結起來。
- 2.5 — Embeddings 與語意搜尋：介紹向量表示法與語意檢索。
- 2.6 — 建立小型搜尋示範：用一個可運行的小範例應用這些基礎概念。

### 模組 3：AI 開發者工具包
- 3.1 — 從 API 呼叫到產品：把 AI 能力轉化為產品思維。
- 3.2 — 呼叫 LLM API：展示實務整合模式。
- 3.3 — 快速原型工具：展示如何將想法快速變成可運行的 demo。
- 3.4 — 建立聊天介面：介紹對話式 AI 的 UI 設計模式。
- 3.5 — AI 應用的 DevOps：涵蓋部署、環境與交付實務。
- 3.6 — 具工具呼叫能力的 AI 運營助手：把 LLM 與工具和真實動作連接起來。

### 模組 4：實務 RAG 與 Context Engineering
- 4.1 — RAG 藍圖：解釋 grounded AI 系統的架構。
- 4.2 — 將資料嵌入向量：涵蓋資料攝取與 embedding 流程。
- 4.3 — 向量資料庫實驗室：探索檢索基礎設施與索引設計。
- 4.4 — 建立 pipeline：串接資料攝取、檢索與生成。
- 4.5 — RAG 優化：提升可靠性、品質與評估能力。
- 4.6 — 小型專案 — Corporate Knowledge Bot：將系統應用在真實產品場景中。

### 模組 5：開發 MCP 伺服器與工具
- 5.1 — MCP 簡介：說明 Model Context Protocol 的角色與用途。
- 5.2 — JSON-RPC 與環境：涵蓋協議機制與執行情境。
- 5.3 — 建立你的第一個 MCP 伺服器：從零開始建立可運行服務。
- 5.4 — 連接真實工具：揭露實際整合方式。
- 5.5 — 除錯與安全：專注於安全且可維運的工具設計。
- 5.6 — 小型專案 — MCP Toolkit：建立一致性的工具生態系統。

### 模組 6：AI 代理與自主性
- 6.1 — 代理與代理架構簡介：定義代理模式與取捨。
- 6.2 — 代理記憶系統與架構：涵蓋跨工作流的記憶與狀態管理。
- 6.3 — Tool Use 與 Function Calling：教授結構化動作選擇。
- 6.4 — Chaining、CoT 與 Pipeline：探索推理流程與協調。
- 6.5 — 建立自主工作流：從設計走向執行。
- 6.6 — 多代理協作：探討共同協調與委派。

### 模組 7：設計 AI 原生系統
- 7.1 — 架構思維與應用模式：從系統設計層面思考擴展性。
- 7.2 — Context Engineering：優化資訊流，以提升推理與品質。
- 7.3 — 設計模式：教授可重複使用的 AI 原生系統模式。
- 7.4 — Human-in-the-Loop 系統：加入審核、批准與監督機制。
- 7.5 — 評估與效能：聚焦於衡量與品質控制。

### 模組 8：生產環境 AI 系統
- 8.1 — 部署策略：介紹真實世界系統的交付模式。
- 8.2 — 安全性與可靠性：涵蓋防護、韌性與信任邊界。
- 8.3 — 可觀測性、監控與日誌：教授生產環境診斷。
- 8.4 — 擴展：處理負載、吞吐量與系統成長。
- 8.5 — 成本優化：聚焦模型與基礎設施效率。
- 8.6 — 效能評估：衡量輸出品質與系統效果。

### 模組 9：進階能力與專業化
- 9.1 — 多模態 AI 系統：探討文字、影像與其他模態的 AI 應用。
- 9.2 — 微調模型：涵蓋對特定任務的適應。
- 9.3 — 強化學習與 RLHF：深入訓練與優化。
- 9.4 — 機制可解釋性：協助理解模型內部與行為。
- 9.5 — 倫理 AI 與偏差：探討公平性、治理與負責任部署。

### 模組 10：職涯轉型與變現
- 10.1 — 職涯路徑：規劃 AI 原生工程師可選擇的機會。
- 10.2 — 建立你的 AI 作品集：將學習轉成可見的能力證明。
- 10.3 — 建立 AI SaaS 應用：結構化產品與商業思考。
- 10.4 — 顧問與自由接案：介紹服務型與專家型商業模式。
- 10.5 — 研究與持續學習：提供長期成長的可持續路徑。

## 語言支援

這門課程主要以英文授課，但公開文件網站設計成支援額外語言與在地化入口。繁體中文（台灣）頁面作為起點，讓使用者能快速進入課程，同時保留核心框架、程式碼與語法名稱為英文，以維持與整個工具生態系統的一致性。
