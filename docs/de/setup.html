Vorab-Lektionen — Technische Umgebung einrichten

Ab Modul 2 wirst du praktische Code-Demonstrationen sehen. Bevor wir mit dem Aufbau KI-gestützter Anwendungen beginnen, müssen wir eine moderne Python-Umgebung vorbereiten, die im weiteren Verlauf des Kurses verwendet wird.

Das Gute daran: Diese Einrichtung musst du nur einmal durchführen. Sobald deine Umgebung korrekt konfiguriert ist, folgt jede Lektion des Kurses genau dem gleichen Workflow.

Dieser Kurs wurde so gestaltet, dass du sofort fertige, lauffähige Implementierungen ausführen und studieren kannst. Jede im Video demonstrierte Lektion existiert bereits im Ordner project-completed/ des Repositories. Das ist der empfohlene Lernweg, weil du dich auf das Verständnis von KI-Konzepten und Software-Engineering-Techniken konzentrieren kannst, ohne jede Lektion von Grund auf neu zu bauen.

Wenn du zusätzliche Praxis möchtest, findest du auch ein passendes project-todo/-Verzeichnis. Diese Dateien enthalten gerüstete Implementierungen mit TODO-Abschnitten, die du selbst abschließen kannst. Sie sind komplett optional und dienen als Herausforderung, nachdem du die fertige Implementierung verstanden hast.

Empfohlener Workflow

  • Lerne die Lektion.

  • Führe die fertige Implementierung aus project-completed/ aus.

  • Studiere, wie der Code funktioniert.

  • Experimentiere mit der Implementierung.

  • Wenn du möchtest, baue die Lektion später erneut mit den Dateien in project-todo/ nach.

Im weiteren Verlauf des Kurses wirst du hauptsächlich mit Folgendem arbeiten:

  • Python 3.11+

  • Visual Studio Code

  • Git

  • Virtuelle Umgebungen

  • APIs für Large Language Models

  • Streamlit

  • Dem Kurs-Repository

Am Ende dieser Lektion wirst du eine vollständige Umgebung haben, mit der du jedes im Kurs demonstrierte Projekt ausführen kannst.

Sprach- / Framework-Auswahl

Python, eine sehr beliebte und empfohlene Sprache, wird im gesamten Kurs verwendet. Die gelernten Methoden und Lektionen lassen sich leicht auf andere Programmiersprachen und Frameworks übertragen (und sogar mit KI-LLMs portieren).

Abschnitt 1 — Betriebssystem vorbereiten

Der Kurs unterstützt macOS und Windows. Linux-Nutzer können den macOS-Anweisungen folgen, da die Befehle identisch sind.

Wenn du Windows verwendest, empfehlen wir dringend Windows Subsystem for Linux (WSL2). Das Repository enthält Bash-Skripte und folgt Linux-Entwicklungsstandards, wodurch WSL2 der nahestehende Erfahrungsrahmen zum während der Kursentwicklung verwendeten Umfeld ist.

1.1 macOS-Setup

Die meisten macOS-Systeme enthalten bereits fast alles, was für diesen Kurs nötig ist. In vielen Fällen ist dieser Abschnitt eher ein Verifikationsprozess als eine vollständige Installation.

Schritt 1 — Terminalzugang prüfen

Öffne die integrierte Terminal-Anwendung.

Du kannst auch iTerm2 installieren, wenn du eine fortgeschrittenere Terminal-Erfahrung bevorzugst.

Anwendung      Empfehlung
-------------   -----------------------------------------------------
Terminal.app    Vollständig unterstützt und standardmäßig installiert.
iTerm2          Optionales Power-User-Tool mit Tabs, Profilen und
                verbesserter Bedienbarkeit.

Tipp

Wenn du dich mit Terminal.app bereits wohl fühlst, besteht keine Pflicht, iTerm2 zu installieren.

Schritt 2 — Python-Installation prüfen

Öffne dein Terminal und führe aus:

python3 --version

Du solltest eine Version ähnlich zu:

Python 3.11.x

Der Kurs verlangt Python 3.11 oder neuer.

Wenn Python nicht installiert ist, gibt es zwei empfohlene Installationsmethoden.

Methode         Empfehlung
-------------   ---------------------------------------------------
Homebrew        Empfohlen für die meisten Entwickler.
python.org      Offizieller Installer der Python Software Foundation.

Wenn du bereits Homebrew nutzt, installiere Python mit:

brew install python3

Wenn Homebrew noch nicht installiert ist, installiere es zuerst und danach Python.

Alternativ kannst du den neuesten Installer von der offiziellen Python-Website herunterladen.

Nach der Installation prüfe erneut:

python3 --version

Schritt 3 — Git-Installation prüfen

Git wird benötigt, um das Kurs-Repository herunterzuladen und den Quellcode zu verwalten.

git --version

Eine erfolgreiche Installation sollte eine Git-Version 2.x oder höher anzeigen.

Wenn Git nicht verfügbar ist, installiere es mit:

brew install git

Schritt 4 — pip prüfen

Python-Pakete werden über pip installiert.

pip3 --version

Wenn pip nicht verfügbar ist, führe aus:

python3 -m ensurepip --upgrade

Warum pip wichtig ist

Jedes in diesem Kurs genutzte KI-Framework – einschließlich Streamlit, LangChain, OpenAI, Anthropic, ChromaDB und viele andere – wird über pip installiert. Die Prüfung jetzt vermeidet unnötige Troubleshooting-Schritte später.

Erwartetes Ergebnis

Bevor du zum nächsten Abschnitt übergehst, sollte dein Mac die folgende Checkliste erfüllen.

Anforderung          Status
------------------  ---------
Terminal verfügbar  ✓
Python 3.11+        ✓
Git installiert     ✓
pip verfügbar      ✓

Checkpoint

Wenn alle vier Punkte oben erfüllt sind, ist deine macOS-Umgebung bereit. Fahre nur dann mit dem nächsten Abschnitt fort, wenn du Windows nutzt. Andernfalls gehe direkt zur finalen Betriebssystem-Prüfung weiter unten in dieser Lektion.

1.2 Windows-Setup (mit WSL2)

Wenn du Windows 10 oder Windows 11 nutzt, empfiehlt dieser Kurs dringend die Entwicklung innerhalb von Windows Subsystem for Linux 2 (WSL2). Obwohl Python auch direkt auf Windows installiert werden kann, bietet WSL2 eine Linux-Umgebung, die vollständig mit modernen KI- und Software-Engineering-Tools kompatibel ist.

Warum WSL2?

  • Der Kurs enthält Bash-Skripte für Setup und Start von Anwendungen.

  • Die meisten KI-Frameworks werden primär unter Linux entwickelt und getestet.

  • Die Paketinstallation ist im Allgemeinen zuverlässiger.

  • Dateipfade und virtuelle Umgebungen verhalten sich konsistenter mit den Beispielen im Kurs.

  • Du bekommst Erfahrung mit demselben Betriebssystem, das viele Cloud-Server und Entwicklungsumgebungen nutzen.

Schritt 1 — Windows Subsystem for Linux installieren

Öffne Windows PowerShell als Administrator.

Führe den folgenden Befehl aus.

wsl --install

Dieser Befehl installiert Windows Subsystem for Linux zusammen mit der Standarddistribution Ubuntu.

Wenn die Installation abgeschlossen ist, starte deinen Computer neu, falls dazu aufgefordert.

Nach dem Neustart startet Ubuntu automatisch und fordert dich auf, einen Linux-Benutzernamen und ein Passwort zu erstellen. Diese Zugangsdaten werden nur innerhalb deiner Linux-Umgebung verwendet.

Hinweis

Dein Linux-Benutzername und dein Linux-Passwort sind getrennt von deinen Windows-Anmeldedaten.

Schritt 2 — WSL-Version prüfen

Öffne PowerShell erneut und führe aus:

wsl --list --verbose

Du solltest eine Ausgabe ähnlich zu dieser sehen:

NAME      STATE     VERSION

Ubuntu    Running   2

Der wichtige Wert ist die Spalte VERSION, die 2 sein sollte.

Wenn deine Installation Version 1 meldet, aktualisiere sie mit:

wsl --set-version Ubuntu 2

Schritt 3 — Ubuntu öffnen

Du kannst Ubuntu auf verschiedene Arten starten.

Methode           Beschreibung
----------------  -------------------------------------------------
Startmenü         Ubuntu direkt aus dem Windows-Startmenü öffnen.
PowerShell        wsl ausführen.
Eingabeaufforderung wsl ausführen.
Windows Terminal  Das Ubuntu-Profil auswählen.

Ab diesem Punkt sollten alle im Kurs gezeigten Befehle im Ubuntu-Terminal ausgeführt werden, sofern nicht anders angegeben.

Schritt 4 — Ubuntu aktualisieren

Bevor du Entwicklungswerkzeuge installierst, aktualisiere das Betriebssystem.

sudo apt update && sudo apt upgrade -y

Dies kann je nach Internetverbindung einige Minuten dauern.

Schritt 5 — Python prüfen

python3 --version

Du solltest Python 3.11 oder neuer installiert haben.

Wenn Python fehlt oder deine Version zu alt ist, installiere es mit:

sudo apt install python3 python3-pip -y

Einige Ubuntu-Versionen benötigen möglicherweise auch:

sudo apt install python3.11 -y

Prüfe danach erneut:

python3 --version

Schritt 6 — Entwicklungswerkzeuge installieren

Mehrere Python-Pakete kompilieren native Erweiterungen während der Installation. Dafür werden die Standard-Build-Tools von Linux benötigt.

sudo apt install build-essential curl git -y

Dadurch werden installiert:

  • GCC

  • G++

  • Make

  • curl

  • Git

Schritt 7 — Git prüfen

Du kannst bestätigen, dass Git verfügbar ist:

git --version

Wenn der Befehl funktioniert, wurde Git korrekt installiert.

Schritt 8 — Virtuelle Umgebung erstellen

Um die Kursumgebung sauber zu halten, erstelle eine virtuelle Umgebung innerhalb des Repositories:

python3 -m venv .venv

Aktiviere sie mit:

source .venv/bin/activate

In PowerShell lautet der Befehl:

.venv\Scripts\Activate.ps1

Schritt 9 — Kurs-Abhängigkeiten installieren

Das Projekt enthält ein Setup-Skript, das die wichtigsten Abhängigkeiten des Kurses installiert.

./setup.sh

Wenn du lieber manuell installierst, schau in die Setup-Dokumentation des Repositories.

API-Schlüssel konfigurieren

Einige Lektionen benötigen Zugang zu externen APIs für Sprachmodelle. Der einfachste Weg ist die Einrichtung eines API-Schlüssels für OpenRouter oder einen anderen kompatiblen Anbieter.

export OPENROUTER_API_KEY="dein-schluessel-hier"

Du kannst auch Umgebungsvariablen für OpenAI oder Anthropic verwenden, je nach Anbieter, den du nutzt.
