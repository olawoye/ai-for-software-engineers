コード学習前 — 技術環境のセットアップ

Module 2 から、実践的なコードを使ったレッスンが始まります。AI を使ったアプリケーションを書き始める前に、コース全体で使う現代的な Python 開発環境を準備する必要があります。

良いニュースは、このセットアップは一度だけで済むことです。環境が正しく整ったら、以降のコースの各レッスンは同じワークフローで進められます。

このコースは、すぐに実行・確認できる完成版の実装を学べるように設計されています。動画の中で紹介された各レッスンのコードは、リポジトリの project-completed/ ディレクトリにすでに含まれています。これは、最初からすべてを自分で構築するのではなく、AI の概念やソフトウェア工学の技法を理解することに集中できるため、おすすめの学習パスです。

さらに実践したい場合は、対応する project-todo/ ディレクトリもあります。ここには、TODO セクションが入った骨組みの実装が含まれていて、理解を深めたあとに自分で完成させることができます。これは任意の挑戦課題です。

推奨学習フロー

  • レッスンを視聴する。

  • project-completed/ の完成版実装を実行する。

  • コードがどのように動くかを調べる。

  • 実装を試しながら変更する。

  • 必要に応じて project-todo/ のファイルを使って、自分でレッスンを再構築する。

このコースの残りでは、主に以下のものを扱います。

  • Python 3.11+

  • Visual Studio Code

  • Git

  • Virtual Environments

  • Large Language Model APIs

  • Streamlit

  • コースのリポジトリ

この章が終わると、コース中で紹介するすべてのプロジェクトを実行できる完全な環境を用意できるようになります。

言語 / フレームワーク選択

このコースでは Python を使います。Python は非常に人気があり、推奨される言語です。ここで学ぶ方法は、他のプログラミング言語やフレームワークにも簡単に応用でき、AI ツールを使って移植することも可能です。
