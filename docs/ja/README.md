# ソフトウェアエンジニアのための AI

講師: Ifeoluwa Mobolaji Olawoye

このコースは、ソフトウェアエンジニアが AI 時代において「ツールの利用者」から「システム設計者」へと成長するための支援をします。AI をブラックボックスとして扱うのではなく、現代の AI 製品の背後にある中核パターンに焦点を当てます。たとえば、チャットインターフェース、検索システム、エージェント、そして本番運用可能な AI アーキテクチャです。

## このコースの目的

現代のエンジニアリング業務は、ソフトウェア開発、プロダクト思考、AI システム設計の交差点にますます位置しています。このコースは、AI を自信を持って扱い、モデルの挙動を理解し、信頼性が高く、根拠のある、有益な実運用システムを届けたいエンジニア向けに設計されています。

## カリキュラム概要

### モジュール 1: 基礎と考え方
- 1.1 — なぜこの変化が重要なのか: AI プラットフォームの変化と、現代 AI システムの 3 つの核心パターンを説明します。
- 1.2 — なぜあなたにとって重要なのか: AI の変化とキャリア、個人の価値を結びつけます。
- 1.3 — あなたのスキルは安全です: 一般的な不安を払拭し、これまでの経験を強みとして再定義します。
- 1.4 — 完全な学習ロードマップ: コース全体の進め方と学習の流れを示します。

### モジュール 2: AI の基礎
- 2.0 — [技術環境のセットアップ](./setup.html): ローカル環境、エディタ、API アクセスを準備します。
- 2.1 — LLM の仕組み: 大規模言語モデルがどのように動くかを高いレベルで説明します。
- 2.2 — Tokens、Context、Completion: コスト、コンテキスト制限、prompt の挙動を扱います。
- 2.3 — Transformer アーキテクチャ: 現代 AI を形作るモデルの概念を紹介します。
- 2.4 — Prompting、Retrieval、Fine-Tuning: prompt 設計パターンと改善戦略をつなげます。
- 2.5 — Embeddings と意味検索: ベクトル表現とセマンティック検索の考え方を学びます。
- 2.6 — ミニ検索デモの構築: 小さな動作する例で基礎を応用します。

### モジュール 3: AI 開発者向けツールキット
- 3.1 — API 呼び出しからプロダクトへ: AI の能力をプロダクト思考へと変換します。
- 3.2 — LLM API の呼び出し: 実用的な統合パターンを示します。
- 3.3 — 迅速なプロトタイピングツール: アイデアをすばやく動くデモへ変える方法を紹介します。
- 3.4 — チャットインターフェースの構築: 会話型 AI 向けの UI パターンを紹介します。
- 3.5 — AI アプリの DevOps: デプロイ、環境、提供手法を扱います。
- 3.6 — Tool Calling を使った AI 運用アシスタント: LLM をツールと実際のアクションに接続します。

### モジュール 4: 実践的な RAG と Context Engineering
- 4.1 — RAG の設計図: grounded AI システムのアーキテクチャを説明します。
- 4.2 — データの埋め込み: データ取り込みと embedding ワークフローを扱います。
- 4.3 — Vector Store Lab: 検索基盤とインデックス設計を検証します。
- 4.4 — パイプラインの構築: 取り込み、検索、生成をつなげます。
- 4.5 — RAG の最適化: 信頼性、品質、評価を改善します。
- 4.6 — ミニアプリ — Corporate Knowledge Bot: 実際の製品シナリオでシステムを適用します。

### モジュール 5: MCP サーバーとツール開発
- 5.1 — MCP 入門: Model Context Protocol とツールアクセスにおける役割を説明します。
- 5.2 — JSON-RPC と環境: プロトコルの仕組みと実行コンテキストを扱います。
- 5.3 — 初めての MCP サーバー: 0 から動作するサーバーを構築します。
- 5.4 — 実世界のツールを接続する: 実用的な統合の方法を紹介します。
- 5.5 — デバッグとセキュリティ: 安全で運用に耐えるツール設計に焦点を当てます。
- 5.6 — ミニプロジェクト — MCP Toolkit: 一貫したツール群のエコシステムを構築します。

### モジュール 6: AI エージェントと自律性
- 6.1 — エージェントとエージェント・アーキテクチャ入門: エージェントのパターンとトレードオフを定義します。
- 6.2 — エージェント記憶システムとアーキテクチャ: ワークフロー全体での記憶と状態管理を扱います。
- 6.3 — Tool Use と Function Calling: 構造化されたアクション選択を学びます。
- 6.4 — Chaining、CoT、Pipelines: 推論フローとオーケストレーションを掘り下げます。
- 6.5 — 自律型ワークフローの構築: 設計から実行へと進みます。
- 6.6 — マルチエージェント協調: 共同調整と委任を検討します。

### モジュール 7: AI ネイティブシステムの設計
- 7.1 — アーキテクチャ思考とアプリケーション・パターン: 大規模なシステム設計を考えます。
- 7.2 — Context Engineering: 情報の流れを最適化して推論と品質を改善します。
- 7.3 — デザインパターン: AI ネイティブシステムの再利用可能な設計パターンを学びます。
- 7.4 — Human-in-the-Loop システム: レビュー、承認、監督メカニズムを追加します。
- 7.5 — 評価とパフォーマンス: 測定と品質管理に重点を置きます。

### モジュール 8: 本番環境向け AI システム
- 8.1 — デプロイ戦略: 実世界のシステム向けの提供パターンを紹介します。
- 8.2 — セキュリティと信頼性: 安全性、回復性、信頼境界を扱います。
- 8.3 — 可観測性、監視、ロギング: 本番環境での診断を学びます。
- 8.4 — スケーリング: 負荷、スループット、システム成長に対応します。
- 8.5 — コスト最適化: モデルとインフラの効率に焦点を当てます。
- 8.6 — パフォーマンス評価: 出力品質と効果を測定します。

### モジュール 9: 高度な機能と専門化
- 9.1 — マルチモーダル AI システム: テキスト、画像など複数のモダリティを扱う AI を探ります。
- 9.2 — モデルのファインチューニング: 特定のタスクへの適応を扱います。
- 9.3 — 強化学習と RLHF: 学習と最適化を深掘りします。
- 9.4 — 機構的解釈可能性: モデル内部と挙動の理解を支援します。
- 9.5 — 倫理的 AI とバイアス: 公平性、ガバナンス、責任ある導入を扱います。

### モジュール 10: キャリア移行と収益化
- 10.1 — キャリア パス: AI ネイティブなエンジニアに選択肢がどのようにあるかを整理します。
- 10.2 — AI ポートフォリオの構築: 学習成果を明確な証拠として可視化します。
- 10.3 — AI SaaS アプリの構築: 製品思考とビジネス思考を整理します。
- 10.4 — コンサルティングとフリーランス: サービス提供と専門家型ビジネスモデルを紹介します。
- 10.5 — 研究と継続学習: 長期的な成長を支える持続可能な道筋を提供します。
