Aulas antes do código — Configuração técnica do ambiente

A partir do Módulo 2, você verá aulas práticas com demonstrações de código. Antes de começar a criar aplicações impulsionadas por IA, precisamos preparar um ambiente moderno de Python que será usado durante o restante do curso.

A boa notícia é que essa configuração é feita apenas uma vez. Depois que o ambiente estiver configurado corretamente, cada aula do curso segue exatamente o mesmo fluxo de trabalho.

Este curso foi desenhado para que você possa executar e estudar imediatamente implementações completas e funcionando. Cada aula demonstrada nos vídeos já existe dentro do diretório project-completed/ do repositório. Esse é o caminho de aprendizado recomendado, porque permite que você se concentre em compreender conceitos de IA e técnicas de engenharia de software sem ter que construir cada aula do zero.

Se você gosta de prática adicional, também encontrará um diretório correspondente chamado project-todo/. Esses arquivos contêm implementações com seções de TODO que você pode completar sozinho. São completamente opcionais e foram pensados como desafio após você já entender a implementação completa.

Fluxo de trabalho recomendado

  • Assista à aula.

  • Execute a implementação completa a partir de project-completed/.

  • Estude como o código funciona.

  • Experimente a implementação.

  • Opcionalmente, recrie a aula mais tarde usando os arquivos dentro de project-todo/.

Durante o restante do curso, você vai trabalhar principalmente com:

  • Python 3.11+

  • Visual Studio Code

  • Git

  • Ambientes virtuais

  • APIs de modelos de linguagem grande

  • Streamlit

  • O repositório do curso

No final desta aula, você terá um ambiente completo capaz de executar todos os projetos demonstrados durante o curso.

Escolha de linguagem / framework

Python, uma linguagem muito popular e recomendada, é usada ao longo deste curso. Os métodos e as lições aprendidas podem ser aplicados facilmente (e até portados com LLMs de IA) para outras linguagens e frameworks.

Seção 1 — Preparando o sistema operacional

O curso suporta macOS e Windows. Usuários de Linux podem seguir as instruções do macOS, porque os comandos são idênticos.

Se você estiver usando Windows, recomendamos fortemente o uso do Windows Subsystem for Linux (WSL2). O repositório inclui scripts em Bash e segue convenções de desenvolvimento Linux, então o WSL2 é a experiência mais próxima do ambiente usado durante o desenvolvimento do curso.

1.1 Configuração no macOS

A maioria dos sistemas macOS já inclui quase tudo o que é necessário para este curso. Em muitos casos, esta seção é apenas um processo de verificação, em vez de uma instalação completa.

Passo 1 — Verificar o acesso ao terminal

Abra o aplicativo Terminal integrado.

Você também pode instalar o iTerm2 se preferir uma experiência de terminal mais avançada.

Application     Recomendação
-------------   -----------------------------------------------------
Terminal.app    Totalmente suportado e instalado por padrão.
iTerm2          Substituto opcional para usuários avançados com abas,
                perfis e melhor usabilidade.

Dica

Se você já está confortável usando o Terminal.app, não há necessidade de instalar o iTerm2.

Passo 2 — Verificar a instalação do Python

Abra seu terminal e execute:

python3 --version

Você deve ver uma versão parecida com:

Python 3.11.x

O curso exige Python 3.11 ou superior.

Se o Python não estiver instalado, há dois métodos recomendados de instalação.

Método          Recomendação
-------------   ---------------------------------------------------
Homebrew        Recomendado para a maioria dos desenvolvedores.
python.org      Instalador oficial fornecido pela Python Software Foundation.

Se você já usa o Homebrew, instale o Python com:

brew install python3

Se o Homebrew ainda não estiver instalado, instale primeiro e depois o Python.

Alternativamente, baixe o instalador mais recente no site oficial do Python.

Depois da instalação, verifique novamente:

python3 --version

Passo 3 — Verificar a instalação do Git

O Git é necessário para baixar o repositório do curso e gerenciar o código-fonte.

git --version

Uma instalação correta deve mostrar uma versão do Git 2.x ou superior.

Se o Git não estiver disponível, instale com:

brew install git

Passo 4 — Verificar o pip

Os pacotes do Python são instalados através do pip.

pip3 --version

Se o pip não estiver disponível, execute:

python3 -m ensurepip --upgrade

Por que o pip importa

Cada framework de IA usado neste curso — incluindo Streamlit, LangChain, OpenAI, Anthropic, ChromaDB e muitos outros — é instalado por meio do pip. Verificar isso agora evita problemas desnecessários mais adiante.

Resultado esperado

Antes de passar para a próxima seção, seu Mac deve cumprir a seguinte lista de verificação.

Requisito          Status
----------------  ---------
Terminal disponível ✓
Python 3.11+       ✓
Git instalado      ✓
pip disponível     ✓

Ponto de controle

Se todos os quatro itens acima estiverem concluídos, seu ambiente macOS está pronto. Continue para a próxima subseção apenas se estiver usando Windows. Caso contrário, siga diretamente para a verificação final do sistema operacional mais adiante nesta aula.

1.2 Configuração no Windows (usando WSL2)

Se você estiver usando Windows 10 ou Windows 11, este curso recomenda fortemente que você desenvolva dentro do Windows Subsystem for Linux 2 (WSL2). Embora o Python possa ser instalado diretamente no Windows, o WSL2 oferece um ambiente Linux totalmente compatível com as ferramentas modernas de IA e engenharia de software.

Por que usar WSL2?

  • O curso inclui scripts em Bash para configuração e execução de aplicativos.

  • A maioria dos frameworks de IA é desenvolvida e testada principalmente em Linux.

  • A instalação de pacotes geralmente é mais confiável.

  • Os caminhos de arquivos e os ambientes virtuais se comportam de forma consistente com os exemplos demonstrados durante o curso.

  • Você ganha experiência usando o mesmo sistema operacional usado por muitos servidores em nuvem e ambientes de desenvolvimento.

Passo 1 — Instalar o Windows Subsystem for Linux

Abra o Windows PowerShell como administrador.

Execute o seguinte comando.

wsl --install

Este comando instala o Windows Subsystem for Linux juntamente com a distribuição padrão do Ubuntu.

Quando a instalação terminar, reinicie o computador, se solicitado.

Depois de reiniciar, o Ubuntu será iniciado automaticamente e pedirá para você criar um nome de usuário e uma senha do Linux. Essas credenciais são usadas apenas dentro do seu ambiente Linux.

Nota

Seu nome de usuário e senha do Linux são diferentes das credenciais de login do Windows.

Passo 2 — Verificar a versão do WSL

Abra o PowerShell novamente e execute:

wsl --list --verbose

Você deve ver uma saída semelhante a:

NAME      STATE     VERSION

Ubuntu    Running   2

O valor importante está na coluna VERSION, que deve ser 2.

Se sua instalação reportar a versão 1, atualize com:

wsl --set-version Ubuntu 2

Passo 3 — Abrir o Ubuntu

Você pode abrir o Ubuntu de várias maneiras.

Método            Descrição
----------------  -------------------------------------------------
Menu Iniciar      Abrir o Ubuntu diretamente no Menu Iniciar do Windows.
PowerShell        Executar wsl.
Prompt de Comando Executar wsl.
Windows Terminal  Selecionar o perfil do Ubuntu.

A partir deste ponto, todos os comandos mostrados neste curso devem ser executados dentro do terminal do Ubuntu, a menos que indicado de outra forma.

Passo 4 — Atualizar o Ubuntu

Antes de instalar ferramentas de desenvolvimento, atualize o sistema operacional.

sudo apt update && sudo apt upgrade -y

Isso pode levar alguns minutos, dependendo da sua conexão com a internet.

Passo 5 — Verificar o Python

python3 --version

Você deve ter Python 3.11 ou superior.

Se o Python estiver ausente ou sua versão for antiga, instale com:

sudo apt install python3 python3-pip -y

Algumas versões do Ubuntu também podem exigir:

sudo apt install python3.11 -y

Verifique novamente após a instalação.

python3 --version

Passo 6 — Instalar ferramentas de desenvolvimento

Vários pacotes do Python compilam extensões nativas durante a instalação. Isso requer as ferramentas padrão de compilação do Linux.

sudo apt install build-essential curl git -y

Isso instala:

  • GCC

  • G++

  • Make

  • curl

  • Git

Passo 7 — Verificar o Git

Você pode confirmar que o Git está disponível:

git --version

Se o comando funcionar, o Git foi instalado corretamente.

Passo 8 — Criar um ambiente virtual

Para manter o ambiente do curso organizado, crie um ambiente virtual dentro do repositório:

python3 -m venv .venv

Ative-o com:

source .venv/bin/activate

Em PowerShell, o comando é:

.venv\Scripts\Activate.ps1

Passo 9 — Instalar dependências do curso

O projeto inclui um script de setup que instala as dependências principais do curso.

./setup.sh

Se você preferir instalar manualmente, consulte a documentação de setup do repositório.

Configuração de chaves de API

Algumas aulas exigem acesso a APIs externas de modelos de linguagem. O método mais simples é configurar uma chave de API do OpenRouter ou de outro provedor compatível.

export OPENROUTER_API_KEY="sua-chave-aqui"

Você também pode usar variáveis de ambiente para OpenAI ou Anthropic, dependendo do provedor que estiver usando.

Resultado final

Ao concluir os passos acima, você terá um ambiente pronto para executar as implementações e experimentos do curso, além de estar preparado para seguir os módulos de IA, RAG, agentes e produção.

Fluxo de trabalho do curso

O recomendado é:

  1. Estudar a teoria da aula.

  2. Executar a implementação completa em project-completed/.

  3. Experimentar mudanças e ajustes.

  4. Recriar a solução em project-todo/ se quiser praticar.

Com esse setup concluído, você estará pronto para seguir todos os módulos do curso em um ambiente consistente e reproduzível.
